## Como registrar um termo

```
### [Termo]
- **Categoria:** Negócio | Produto | Técnico | Sigla
- **Definição:** O que significa no contexto deste projeto.
- **Usado em:** [ex: contratos, interface do produto, comunicação interna]
- **Sinônimos ou variações:** [outros termos usados para a mesma coisa, se houver]
- **Não confundir com:** [termo parecido mas com significado diferente, se houver]
```

> **Dica:** Registre o termo como ele é usado pelo cliente — não como você acha que deveria ser usado. A consistência de linguagem é o que torna este arquivo útil para os agentes.
