# conhecimento/produto/fluxos-e-jornadas/fluxos-mapeados/

Fluxos de usuário mapeados pela skill `flow-mapping`, em Mermaid — rascunhos não validados, separados por modo.

## Subpastas

| Pasta | Conteúdo |
|---|---|
| `existentes/` | Fluxos existentes (as-is), mapeados a partir de achados de pesquisa ou documentação de sistema atual — ver `existentes/index.md` |

> `futuros/` (fluxos to-be, mapeados a partir de requisitos e regras de negócio ainda não implementados) ainda não existe — é criada quando a skill `flow-mapping` gerar o primeiro fluxo futuro. Só adicione a linha na tabela acima depois que a pasta existir de fato.

## Quando consultar

Consulte antes de propor uma solução para um fluxo que já foi mapeado, ou para entender o comportamento observado/esperado de uma jornada. Para um fluxo ganhar ID (`FLXxxx`) e poder ser citado em riscos, dores e decisões, ele precisa ser incorporado ao catálogo `../fluxos-e-jornadas.md` — a skill `flow-mapping` sugere isso ao final de cada mapeamento. O arquivo daqui continua sendo o detalhamento (diagrama).
