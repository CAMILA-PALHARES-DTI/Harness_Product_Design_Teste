# conhecimento/desenvolvimento/

Briefings funcionais e Specs de desenvolvimento do projeto. Os fluxos e jornadas ficam em `conhecimento/produto/fluxos-e-jornadas/`.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `briefings-funcionais/` | Briefings funcionais de features, geradas pela skill `intent` — ver `briefings-funcionais/index.md` |
| `specs/` | Specs de desenvolvimento (pacotes que agrupam User Stories), geradas pela skill `create-spec` a partir de um briefing, com ou sem artefato visual — ver `specs/index.md` |

## Quando consultar

Consulte ao receber descrições de processos, ao mapear dependências entre etapas ou ao precisar entender como um módulo se conecta com outros sistemas. Consulte `briefings-funcionais/` ao construir um protótipo visual ou refinar uma feature que já tenha sido especificada. Consulte `specs/` ao gerar as Specs de uma feature (Specs com User Stories, com ou sem protótipo).
