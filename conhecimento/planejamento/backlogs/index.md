# conhecimento/planejamento/backlogs/

Quebras de um direcionador (roadmap macro, OKR, épico) em itens de trabalho — geradas pela skill `define-deliverables`. Cada arquivo lista apenas nome e uma frase de descrição por item; não contém refinamento, estimativa ou critério de aceite.

## Convenção de arquivos

`backlog-[recorte]-[YYYY-MM-DD].md`

Cada backlog deve conter as seções definidas pela skill `define-deliverables`: direcionador, itens já existentes no board, itens propostos (por Epic/Feature), itens bloqueados e pendências.
