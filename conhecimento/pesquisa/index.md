# conhecimento/pesquisa/

Repositório de pesquisa do projeto — planejamento, execução, coleta e síntese.

## Subpastas

| Pasta | Conteúdo |
|---|---|
| `planos/` | Planos de pesquisa — objetivos, roteiros, critérios de recrutamento |
| `artefatos/` | Guias de entrevista, formulários, protótipos usados em pesquisa |
| `coleta/` | Transcrições, gravações, notas brutas de campo |
| `notas-estruturadas/` | Notas de análise por participante — já processadas |
| `relatorios/` | Relatórios de síntese e recomendações finais |

## Fluxo de pesquisa

`planos/` → `artefatos/` → `coleta/` → `notas-estruturadas/` → `relatorios/`

As skills `plan-research`, `create-artifacts`, `process-research-data` e `interpret` alimentam esta cadeia. A coleta com os participantes acontece fora do harness; seus dados brutos entram por `process-research-data`, que os salva em `coleta/` antes de gerar as notas estruturadas.
