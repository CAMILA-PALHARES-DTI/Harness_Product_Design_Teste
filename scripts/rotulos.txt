# rotulos.txt — dicionário de rótulos que os sensores leem no TEXTO dos arquivos gerados.
#
# Por que existe: o CLAUDE.md manda escrever o conteúdo dos arquivos no idioma configurado (português ou
# inglês). Títulos de seção, rótulos de campo, nomes de coluna e alguns valores de frontmatter mudam de
# texto com o idioma, mas os sensores (validar-output.sh de cada skill e scripts/*.ps1) precisam reconhecê-los
# em qualquer idioma. Em vez de cada sensor guardar o seu próprio texto fixo, todos leem este arquivo.
#
# Formato (uma linha por conceito):   chave | português (Brasil) | inglês
#   - Dentro de uma coluna, variantes extras do mesmo idioma são separadas por ';'.
#   - Chaves repetidas SOMAM variantes (usado em listas, ex: interpretacao).
#   - Linhas começando com '#' e linhas em branco são ignoradas. Um rótulo não pode conter '|'.
#   - Os sensores comparam sem diferenciar maiúsculas de minúsculas e aceitam as variantes de TODAS as colunas
#     (um arquivo em inglês com um título em português ainda passa) — a coluna certa para escrever, porém, é a
#     do idioma configurado no CLAUDE.md: as skills devem usar o rótulo daquela coluna, sem inventar variações.
#   - Para acrescentar um idioma, acrescente uma coluna em TODAS as linhas (os sensores já leem qualquer número
#     de colunas) e peça às skills para usá-la.
#
# NÃO entram aqui (permanecem iguais em qualquer idioma, como o CLAUDE.md define): nomes de arquivo e pasta,
# chaves de frontmatter e de blocos YAML, valores de enum de YAML (confirmado, hipotese, pronta_para_dev...),
# IDs (DORxxx, DEPxxx, RISxxx, Dxxx, FLXxxx, OKR-N, SCR-NN, US-N.M, SPEC-N) e os marcadores [a confirmar] e
# [BLOQUEADO até DEPxxx].
#
# Chaves: secao.* = título de seção "## ..." · campo.* = rótulo em linha "**Rótulo:**" · coluna.* = cabeçalho de
# tabela · valor.* = valor de frontmatter/status · art.* = seções dos artefatos de pesquisa · bdd.* = rótulos do
# critério de aceite · marcador.* = marcador em texto · interpretacao = termos de linguagem interpretativa.
